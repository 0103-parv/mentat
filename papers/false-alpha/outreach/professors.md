# Professor outreach list — false-alpha paper

All names/affiliations verified via web search (June 2026). **Do NOT trust any email address
from memory — get the real one from the faculty page linked below.** Post to SSRN/arXiv
FIRST, then email with the link (a posted preprint gets far better responses than "a draft").

**Rule: personalize every email. Reference their specific work (hooks below). Do not mass-blast

reply; one good reply is a win.

### 2. Campbell R. Harvey — Duke (Fuqua)

### 6. Emmanuel Candès — Stanford Statistics (knockoffs / FDR control / selective inference)
His knockoff filter is *the* modern false-discovery-control method. Our paper hits the same
false-discovery problem in strategy search and finds analytic effective-N corrections fail

genuinely elegant connection.)
- Pages: https://candes.su.domains/ · https://profiles.stanford.edu/emmanuel-candes
- Hook: *"Your knockoffs/FDR framework — I ran into the same false-discovery problem in

  I'm curious whether a knockoff-style construction would apply to backtested strategies."*
